# 多功能计算器数学原理

> 本文档描述墨麒麟记账 App 内置多功能计算器的数学原理、精度规范与验证用例。
> 所有计算器均采用 150ms 输入防抖（`LaunchedEffect` + `delay`），输入即算，无需点击按钮。

---

## 一、定投计算器（DCA）

### 1.1 输入参数

| 参数 | 符号 | 类型 | 约束 |
|------|------|------|------|
| 每期投入金额 | PMT | BigDecimal | >= 0 |
| 预期年化收益率 | R | Double | 0% ~ 20% |
| 投资年限 | Y | Int | 1 ~ 50 |
| 定投频率 | freq | 枚举 | 每周(52) / 每两周(26) / 每月(12) |
| 初始本金 | PV | BigDecimal | >= 0，默认 0 |

### 1.2 周期参数推导

```
每年期数 N = freq.periodsPerYear
  每周   52
  每两周  26
  每月   12

总期数 T = Y * N
单期利率 r = R / N
```

### 1.3 逐期复利递推

采用 **逐期复利递推法** 而非简化公式，保证精度并支持逐年快照。

```
余额(0) = PV
投入(0) = PV

对于第 p 期（p = 1, 2, ..., T）：
  利息(p) = 余额(p-1) * r
  余额(p) = 余额(p-1) + 利息(p) + PMT
  累计投入(p) = 累计投入(p-1) + PMT

每到年末（p % N == 0）或最后一期，记录快照：
  年份   = ceil(p / N)
  年末资产 = 余额(p)
  累计投入 = 累计投入(p)
  累计收益 = 余额(p) - 累计投入(p)
```

### 1.4 精度规范

- 中间计算精度：`setScale(10, HALF_UP)`
- 输出精度：`setScale(2, HALF_UP)`
- 使用 `BigDecimal` 避免浮点累积误差
- 单期利率除法精度：`divide(ppy, 10, HALF_UP)`

### 1.5 收益率计算

```
总收益率 = (累计收益 / 累计投入) * 100%
```

### 1.6 智能格式化

```
资产 >= 1亿  显示为 X.XX亿
资产 >= 1万  显示为 X.XX万
否则        千分位格式 X,XXX.XX
```

### 1.7 验证用例

| 场景 | 参数 | 预期终值 |
|------|------|----------|
| 基准 | 月投1000, 年化6%, 10年, 无初始本金 | 约 163,879.35 |
| 零收益 | 年化0% | 终值 = 总投入 |
| 纯复利 | 初始10万, 每期0, 年化6%, 10年 | 约 179,084.77 |

### 1.8 目标模式（反向求解）

当用户设定目标金额而非每期投入时，反向求解所需的每期投入 PMT。

#### 1.8.1 核心公式

基于普通年金终值公式变形：

```
已知：FV（目标终值）、R（年化收益率）、Y（年限）、freq（频率）、PV（初始本金）
求：PMT（每期投入）

i = R / N          （单期利率）
N = freq           （每年期数）
T = Y * N          （总期数）
fvFactor = (1 + i)^T  （终值因子）

PMT = (FV - PV * fvFactor) / ((fvFactor - 1) / i)
```

#### 1.8.2 边界处理

| 场景 | 处理逻辑 | 用户体验 |
|------|----------|----------|
| 目标 <= PV复利终值 | PMT <= 0 | 显示“现有本金已足够” |
| 收益率 = 0% | 退化为线性：PMT = (FV - PV) / T | 正常显示 |
| 计算结果为负数 | 数据异常 | 提示检查目标金额 |

#### 1.8.3 取整策略

```
精确值：PMT.setScale(2, CEILING)  （保留两位小数）
显示值：向上取整到十位
  pmtRounded = ceil(PMT / 10) * 10

示例：2856.43 -> 2860
```

#### 1.8.4 周/日金额拆解

```
周均 = pmtRounded * N / 52  （向上取整）
日均 = pmtRounded * N / 365 （向上取整）
```

#### 1.8.5 达标日期计算

```
targetDate = currentDate + Y 年
显示为 “{targetYear}年{targetMonth}月”
```

#### 1.8.6 验证用例

| 场景 | 参数 | 预期月供 |
|------|------|----------|
| 基准 | 目标100万, 10年, 6%, 无本金 | 约 6,110 |
| 有本金 | 目标100万, 已有50万, 10年, 6% | 显著低于6,110 |
| 本金充足 | 目标50万, 已有60万, 10年, 6% | 显示“已足够” |
| 零收益 | 目标100万, 10年, 0%, 无本金 | 约 834 |

## 二、复利计算器（复利实验室）

### 2.1 设计理念

A/B 对比模式，用输入框精确控制参数，实时 Canvas 曲线图可视化差异。

### 2.2 输入参数（A/B 双组）

| 参数 | 符号 | 类型 | 约束 | 输入方式 |
|------|------|------|------|----------|
| 初始本金 | PV | Float | 10,000 ~ 1,000,000 | 数字输入框 + ¥ 前缀 |
| 年化收益率 | R | Float | 0% ~ 20% | 数字输入框 + % 后缀 |
| 投资年限 | Y | Int | 1 ~ 50 | 数字输入框 + 年后缀 |

### 2.3 公式

```
终值 FV = PV * (1 + R/100)^Y

其中：
  PV = 初始本金
  R  = 年化收益率（百分比）
  Y  = 投资年限
```

### 2.4 逐年快照

```
第 y 年终值 = PV * (1 + R/100)^y
第 y 年累计收益 = 第 y 年终值 - PV
倍数 = 终值 / PV
```

### 2.5 对比模式

点击「➕ 添加对比组」启用 B 组参数，Canvas 同时绘制两条曲线：
- A 组：绿色（#4CAF50）
- B 组：橙色（#FF6D00）
- 差额 = B 终值 - A 终值

### 2.6 预设场景

| 预设名 | A 组 | B 组 | 教学目的 |
|--------|------|------|----------|
| 费率之差 | 10万, 8%, 20年 | 10万, 7%, 20年 | 1% 费率差异的长期影响 |
| 时间之力 | 10万, 6%, 20年 | 10万, 6%, 30年 | 多持10年的复利威力 |
| 通胀侵蚀 | 10万, 5%, 15年 | 10万, 2%, 15年 | 实际购买力缩水 |
| 72法则验证 | 10万, 7.2%, 10年 | 10万, 3.6%, 20年 | 72/r ≈ 翻倍年限 |

### 2.7 72 法则

```
翻倍年限 ≈ 72 / 年化收益率(%)

示例：年化 6% → 72/6 = 12 年翻倍
```

## 三、个人所得税（税后收入翻译器）

### 3.1 设计理念

不是"算个税"，而是"翻译税后收入"。
支持月薪、年终奖、劳务报酬三种收入类型，堆叠条形图直观展示收入构成。

### 3.2 收入类型

| 类型 | 起征点 | 税率表 | 特殊规则 |
|------|--------|--------|----------|
| 月薪 | 5,000 元/月 | 7级累进（综合所得） | 五险一金可扣除 |
| 年终奖 | — | 7级累进（单独/并入可选） | 单独计税按月均分查表 |
| 劳务 | 800 元/次 | 3级预扣率 | 无专项附加扣除 |

### 3.3 中国个税 7 级超额累进税率（综合所得）

起征点：5,000 元/月（60,000 元/年）

| 级数 | 年应纳税所得额 | 税率 | 速算扣除数 |
|------|----------------|------|------------|
| 1 | <= 36,000 | 3% | 0 |
| 2 | 36,001 ~ 144,000 | 10% | 2,520 |
| 3 | 144,001 ~ 300,000 | 20% | 16,920 |
| 4 | 300,001 ~ 420,000 | 25% | 31,920 |
| 5 | 420,001 ~ 660,000 | 30% | 52,920 |
| 6 | 660,001 ~ 960,000 | 35% | 85,920 |
| 7 | > 960,000 | 45% | 181,920 |

### 3.4 月薪计算公式

```
月应纳税所得额 = 税前月薪 - 五险一金 - 专项附加扣除 - 5,000
年应纳税所得额 = max(月应纳税所得额, 0) * 12

年个税 = 年应纳税所得额 × 对应税率 - 速算扣除数
月个税 = 年个税 / 12（四舍五入到分）
税后到手 = 税前月薪 - 五险一金 - 月个税
```

### 3.5 年终奖单独计税

```
月均 = 年终奖 / 12
根据月均查税率表：
  <= 3,000     → 3%,  速算扣除数 0
  <= 12,000    → 10%, 速算扣除数 210
  <= 25,000    → 20%, 速算扣除数 1,410
  <= 35,000    → 25%, 速算扣除数 2,660
  <= 55,000    → 30%, 速算扣除数 4,410
  <= 80,000    → 35%, 速算扣除数 7,160
  > 80,000     → 45%, 速算扣除数 15,160

个税 = 年终奖 × 税率 - 速算扣除数
```

### 3.6 劳务报酬预扣

```
应纳税所得额 = max(劳务收入 - 800, 0)

  <= 20,000  → 税率 20%
  <= 50,000  → 税率 30%, 速算扣除数 2,000
  > 50,000   → 税率 40%, 速算扣除数 7,000

预扣个税 = 应纳税所得额 × 税率 - 速算扣除数
```

### 3.7 边际税率跳档提示

当用户输入接近税率跳档点时，提示：
> "当前适用税率 X%，再增加 ¥Y 将跳档至 Z%"

### 3.8 构成条形图

堆叠条形图展示收入三部分：
- 绿色（#4CAF50）：税后到手
- 红色（#FF5722）：个税
- 灰色（#90A4AE）：五险一金

使用 `Float.MIN_VALUE` 保证 `weight()` 参数始终 > 0。

## 四、储蓄目标计算器

### 4.1 产品定位

核心使命不是“算收益”，而是“算进度”与“管现金流”。
解决中短期、确定性支出（买车、旅游、首付、备用金）的攒钱焦虑。

| 维度 | 定投计算器 | 储蓄目标计算器 |
|------|-----------|---------------|
| 核心驱动 | 收益率驱动（钱生钱） | 本金驱动（人挣钱） |
| 时间跨度 | 5-30年 | 3个月-3年 |
| 利率处理 | 核心变量 | 次要变量，默认2% |

### 4.2 输入设计（目标-现状-节奏）

| 字段 | 类型 | 默认值 | 设计意图 |
|------|------|--------|----------|
| 目标金额 | 数字键盘 | 50000 | 攒钱目标 |
| 期望达成日 | 数字输入框 | 12个月 | 比“X年”更直观 |
| 已存金额 | 折叠选项 | 0 | 非必填 |
| 每月可存 | 数字键盘 | 空 | 核心变量 |
| 预估年化 | 快捷标签 | 2% | 默认货币基金水平 |

### 4.3 双模式计算

#### 模式A：已知目标日期 → 算每月需存（默认）

```
剩余目标 = 目标金额 - 已存金额 * (1+r)^N
年金因子 = ((1+r)^N - 1) / r
月存额 = 剩余目标 / 年金因子

当利率=0时：月存额 = (目标金额 - 已存金额) / 剩余月数
```

#### 模式B：已知每月可存 → 算达成日期

```
逐月递推：余额 = 余额 * (1+月利率) + 每月可存
找到余额 >= 目标金额的首个月份
```

### 4.4 进度可视化

```
进度百分比 = 已存金额 / 目标金额 * 100%
LinearProgressIndicator + 蓝色主题
```

### 4.5 弹性空间提示

```
如果每月少存500元：
  新月存额 = max(原月存额 - 500, 1)
  重新计算达成月数
  推迟月数 = 新月数 - 原月数
```

### 4.6 验证用例

| 场景 | 参数 | 预期月存 |
|------|------|----------|
| 基准 | 目标5万, 12个月, 已存0, 利率0% | 约 4,167 |
| 有积蓄 | 目标5万, 已存2万, 剩余6个月 | 约 5,000 |
| 利率影响 | 目标5万, 12个月, 利率2% | 略低于4,167 |
```

## 五、分期付款计算器

### 5.1 等额本息（手续费模式）

```
每月本金 = 消费金额 / 期数
每月手续费 = 消费金额 * 每期手续费率
每期还款 = 每月本金 + 每月手续费
总手续费 = 每月手续费 * 期数
还款总额 = 消费金额 + 总手续费
实际费率 = 总手续费 / 消费金额 * 100%
```

## 六、分期计算器（APR反推）

### 6.1 设计理念

核心使命不是“算月供”，而是“揭穿低息幻觉”。
用户通常知道“每月还多少”，而非“利率是多少”。让算法根据 总金额+期数+月供 反推真实APR。

### 6.2 双模式架构

| 模式 | 输入 | 输出 | 价值 |
|------|------|------|------|
| 模式A（核心） | 总金额 + 期数 + 每期还款额 | 真实APR | 揭穿低息幻觉 |
| 模式B（辅助） | 总金额 + 期数 + 年利率 | 每期还款额 | 传统计算 |

### 6.3 反推APR算法（二分法）

```
已知：P（本金）、M（月供）、n（期数）
求：月利率 r，使得等额本息公式成立

f(r) = P * r * (1+r)^n / ((1+r)^n - 1) - M = 0

使用二分法求解（比牛顿法更稳健）：
  low = 0, high = 0.1（月利率上限10%）
  重复100次：
    mid = (low + high) / 2
    if |f(mid)| < 1e-8  return mid
    if f(mid) > 0  high = mid  else  low = mid

APR = r * 12 * 100%
```

### 6.4 边界处理

| 场景 | 处理 |
|------|------|
| 月供*期数 < 本金 | 提示“输入有误” |
| 月供 = 本金/期数 | APR = 0%（无利息） |
| 迭代不收敛 | 提示“无法收敛” |

### 6.5 手续费模式

```
每期收取：effectiveM = M + fee
一次性收取：effectiveP = P - fee
两种模式APR差异巨大，必须区分清楚。
```

### 6.6 验证用例

| 场景 | 参数 | 预期APR |
|------|------|----------|
| 基准 | 12000, 12期, 月供1072 | 约 13.76% |
| 月费率0.6% | 12期, 无手续费 | 约 13.03% |
| 先息后本 | 月息0.5%, 12期 | 6.00% |
```
